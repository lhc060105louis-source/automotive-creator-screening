YouTube API 配置
使用说明：需要 YouTube Data API v3 密钥。
1. 前往 Google Cloud Console → 启用 YouTube Data API v3 → 创建 API 密钥
2. 将密钥填入下方并保存
3. 如从本地文件打开，部分浏览器会因安全策略阻止 API 请求。建议在终端运行 python3 -m http.server 8080 后通过 http://localhost:8080 访问

接入说明：配置后，添加 KOL 时可一键从 C 端情感档案 API 自动获取评论区 VOC 数据，填入「评论质量」「VOC话题深度」「负面VOC识别价值」「历史车主反馈」四个字段，并自动检测技术声明风险信号。

云端数据共享（Supabase）未配置
团队共享配置（5 分钟完成）：
1. 前往 supabase.com 免费注册 → 新建项目（选欧洲区域）
2. 进入项目 → 左侧 SQL Editor → 粘贴下方建表语句并执行
3. 进入 Settings → API → 复制 Project URL 和 anon public key
4. 填入下方并保存 → 所有团队成员使用相同的 URL 和 Key 即可共享数据
